# No-ad pack

Aliases: no ad pack, ad free, go ad-free

Product context: `radioly/pfm-kb/modules/no-ad-pack.md`

## What it is

Purchased / granted ad-free entitlement.

## Graph anchors

CODE SEARCH `no_ad` / ad-free under payments / ads entitlements.


## Key product notes

A time-boxed purchase that turns off **network mid-roll** and **most promotional first-party player clips** for a number of days. It is not a subscription, not unlock, and not a banner-off guarantee.

## Risks

- Claiming ad-free covers all ad surfaces without evidence.
