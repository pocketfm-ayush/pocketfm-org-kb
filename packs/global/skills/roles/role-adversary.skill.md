# Skill: Role — Adversary

**When:** Red-team a plan, PR, or deploy claim; find what was not checked.
**Use inside:** `harness-plan-critique`, `harness-response-recheck`.

## Attacks

- What single skipped tool would hide an outage?
- What assumption, if false, invalidates the plan?
- What protected path or secret could leak?
- What test was not run?

Output only findings with severity. No cheerleading.
