# Streak and rewards

## Journey
1. Listening progress accrues toward daily streak.
2. Streaks/rewards UI shows progress and claim CTAs.
3. Ads offerwall may grant alternate rewards.
4. Server confirms credit; wallet/rewards refresh.

## Modules
- [streaks](../modules/streaks.md)
- [rewards](../modules/rewards.md)
- [ads](../modules/ads.md)
- [player](../modules/player.md)

## Failure modes
- Client shows claimable state before server ack.
- Offerwall completion without reward fulfilment job.
