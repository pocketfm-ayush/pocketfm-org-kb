# Experience re-engage loop

## Journey
1. Eligibility/view events hit experience topics.
2. Reengage reward / Discover / key tropes / shared event workers update state.
3. Comms/MoEngage siblings may notify.
4. Next session shows refreshed experience surfaces.

- Discover tracking without corresponding feed change.
