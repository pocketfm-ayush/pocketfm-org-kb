# Device-specific art

Aliases: DS thumbnail, device thumbnail, search artwork, cover art override

## What It Is

Some devices get a different cover for the same show. Search stamps that
art on the row after the list is chosen.

## User-Visible Invariants

- Same show, different device, can show different art.
- Art is not a ranking change.

## Client Behavior

Server attaches the media. iOS new-design art updates are part of this.
