# Streak and rewards

## Journey
1. Listening progress accrues toward streak.
2. Streaks/loyalty UI shows progress; Live Activity may update.
3. Rewarded ads / daily login / offerwall grant alternate rewards.
4. Server confirms credit.

- [streaks](../modules/streaks.md)

## Failure modes
- Client shows claimable before server ack.
- Live Activity stale vs in-app streak.
