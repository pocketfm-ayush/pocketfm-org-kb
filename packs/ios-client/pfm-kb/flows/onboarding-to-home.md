# Onboarding to home

## Journey
1. New listener completes onboarding/OTP.
2. Optional profile creation.
3. GDPR/consent gates apply when required.
4. Shell routes into home.

- [auth-and-onboarding](../modules/auth-and-onboarding.md)

## Failure modes
- Consent skipped incorrectly in regulated locales.
- OTP failure without recoverable UI.
